# 超鬼王刷门票框架

在超鬼王任务的“刷超鬼王门票”分组启用 `ticket_farm.enable` 后，先运行刷票阶段；开始时从探索页读取每日门票进度（如 `49/50`、`50/50`），战斗中从奖励页右上角读取，满额后进入原有的超鬼王挑战流程。默认关闭，兼容已有配置。

- `battle_task`：`EvoZone`（觉醒）、`Orochi`（御魂）、`Exploration`（探索）。直接调用对应 `ScriptTask.run()`，沿用该任务的层数、阵容、组队和加成配置，不要求其独立调度开关开启。
- 一次进入副本后持续刷票，在关闭每场奖励页面或处理队友邀请前读取门票数量。子任务使用配置副本，不更改原刷本配置或独立任务的下次运行时间。
- 选择探索刷票时，在进入探索地图及章节结束返回地图时检查结界挑战券。达到探索配置中「绘卷模式」分组的突破票阈值（默认 25）就在当前超鬼王任务内执行个人突破，按个人突破的次数、留票和退出规则结束。回到同一轮超鬼王任务后，只重新读取超鬼王门票进度；若还需要刷票，先继续探索，到下一次章节结束时再检查结界挑战券。无需开启探索的绘卷模式或个人突破的独立调度；不会另外排队执行普通探索或绘卷任务。
- 普通刷票时，读取门票后直接从探索页进入觉醒、御魂或对应探索章节；未达上限时留在当前副本继续下一场，不每场退回探索页。满额、达到清突破票阈值、战斗失败、连续三场未读到门票数或本轮时间耗尽时执行正常收尾。此改动仅用于刷票适配层；配置中明确启用的庭院加成开关、切换御魂等准备操作仍保留。
- 每日当前数量和上限都以游戏界面为准，不手动配置上限、不做本地累计或持久化，也不在本地处理跨日重置。
- 确认满额后（包括启动时已满额），先用新截图导航并确认返回庭院，再从庭院经活动列表进入超鬼王；未能返回庭院则暂停本轮。超鬼王 session 排除经结界突破进入式神录的捷径，防止将式神录的返回按钮误当成活动入口。
- `limit_time`：本轮刷票的软时间上限，默认 30 分钟，当前战斗会正常收尾。超鬼王挑战的时间和次数另行计算。

## 探索页数量识别

`TicketFarmMixin.read_daily_ticket_progress(self) -> tuple[int, int] | None`：

1. 导航到探索页，截图并确认页面后，用 `DigitCounter` 读取顶部的每日门票进度。1280×720 原图的区域为 `(936, 14, 100, 36)`，格式是 `(x, y, 宽, 高)`，不含窗口边框；资源定义位于 `md/ocr.json`。
2. `49/50` 返回 `(49, 50)`，继续刷票；`50/50` 返回 `(50, 50)`，停止刷票并挑战超鬼王。当前数量必须是非负整数，上限必须是正整数。
3. 仅在每轮刷票启动时读取探索页；页面未确认或计数识别无效返回 `None`，禁止用战斗次数估算。

## 战斗奖励页数量识别

刷票任务的奖励页处理器在原有点击关闭/队友邀请之前，用 `DigitCounter` 读取右上角 `(1138, 6, 100, 36)` 区域。读到 `1/50` 时报告 `(1, 50)`，沿用游戏计数，不做本地加一或累计。

觉醒、御魂、探索共用这条刷票专用处理逻辑，独立运行原任务时不受影响。每场独立读取奖励页；连续一、两场未读到时继续刷，第三场仍未读到才暂停本轮并等待下次调度。任一场读到有效门票数就清零连续漏读次数；同一轮中途清突破票不清零。不使用上一场读数替代本场读数，也不每场返回探索页。达到上限后，当前副本正常收尾，再进入超鬼王挑战。

探索页和奖励页的计数识别都依赖项目 OCR 服务；不从活动首页读取。次日是否恢复刷票由游戏计数决定。

掉落门票时，“今日已获得裂变之眼”弹窗也会被识别为奖励页：计数仍统一读取右上角，不读取中央进度；随后复用普通奖励页的 `random_click()` 范围关闭弹窗。重新截图后继续处理底层奖励页，避免弹窗遮挡导致流程停滞。同一场战斗的所有奖励帧都未读到有效计数时，只记一次漏读。

探索页计数识别失败、连续三场奖励页漏读、刷本失败/没有完成战斗或本轮时间耗尽时，按超鬼王调度中的 `wait_interval` 延后重试；不进入挑战阶段。其他异常照常交给脚本错误处理。

## 本期活动入口

默认庭院 → 活动列表 → OCR 选择“版本” → 识别“祸至无日”海报 → 前往活动 → 活动首页。

活动首页用右侧入口中“降临”二字识别，黑字或白字模板任一命中即可。1280×720 原图模板区域为 `(943, 151, 44, 119)`，搜索区域为 `(929, 137, 72, 147)`。进入超鬼王的点击范围单独定义为 `(886, 28, 150, 238)`，不使用小文字模板作为点击范围。活动首页左上返回按钮直接回到庭院。

鬼王挑战页用右上角疲劳图标确认，兼容新旧两种尺寸，不匹配旁边的疲劳数值。

## 挑战阵容

一至四星共用一套阵容，五星和六星各自独立。在超鬼王的「切换御魂」分组启用后，填写 `组号,队伍号`（如 `1,2`）或 `分组名称,队伍名称`（如 `默认分组,队伍1`），留空则沿用当前阵容。

切换阵容组时，脚本从活动页右侧阵容栏展开面板，识别新版预设图标或旧版齿轮后点击整条阵容栏。面板展开后定位「出战」，选定队伍后点击「出战」，并在出现御魂不一致提示时点击「确定」。阵容和御魂在同一步应用。一至四星之间切换目标时沿用当前阵容。

系统租借队伍可按完整标题选择，例如 `队伍租借,第7日群体通用阵容`。名称 OCR 覆盖无编号标题的左侧起点。分组和队伍列表回到顶部各最多滑动三次。

展开后先检查当前高亮分组和可见预设。找不到时才滑动，每滑一次就重新截图查找，找到目标立即停止滑动。选中队伍后点击「出战」。

准备挑战时，从左侧「自己发现」头像底部读取由左到右连续亮起的橙色星标。已有鬼王和新召唤的鬼王都按实际星级选择阵容及追击方式；星标无法确认时保留当前阵容，使用普通追击。

旧配置按一星到四星的顺序沿用第一项非空阵容，已保存的一至四星共用配置优先。原「一次性切换」和战斗内预设开关由活动页切换流程取代；之前仅启用战斗内预设的配置需要开启本分组总开关。

## 裂变之眼合成模板

一至五星按各行的星级文字识别，限制在对应行附近搜索，避免外观相近的一星、二星图标混淆；选中后的高亮状态也已验证。合成入口、开始合成、一键添加和空位模板已按本期界面更新，关闭按钮沿用已验证可用的模板。

点击条目前先 OCR 核对实际星级文字；选择后必须重新截图，再核对该行星级文字及“已放入”数量。只有文字与配置星级完全一致、已放入数量等于所需数量，才点击开始合成。“持有”数量、条目模板匹配和空位数量都不能代替这个校验。识别失败或材料不足时跳过，点击合成后等待结果确认，超时停止，避免重复点击。

空位模板验证使用 `match_all_any()` 去重，已验证三空位、放入两份一星后剩一空位、关闭重开恢复三空位。购买合成券提示未出现，相关旧模板尚未验证。
